A Python program — standard library only, no network — that writes one line to /output/entry.txt: the funniest commit message for a fix that made everything worse. The line is 85 characters, inside the competition's gate of 1 to 100 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
